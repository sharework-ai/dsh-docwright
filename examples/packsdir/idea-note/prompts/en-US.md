# Idea Note

Write one development note for the selected idea (targetIndex into the board's `ideas[]`).

## Output requirements

- `ideaId`: copy the selected idea's ideaId verbatim.
- `title`: copy the selected idea's title verbatim.
- `note`: at least 20 characters — what to build and the first implementation step.

## Hard constraints

1. `ideaId` must equal the selected idea's `ideaId` character for character (the engine names the artifact after it).
2. `note` is at least 20 characters.
